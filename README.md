### 1. Project name: "Fit Log"

### 2. Description
FitLog project a complete workout management experience where users can browse exercises, view workout details, add workouts to today's plan, save workouts for later, and fitness routine daily check.
The project on a clean UI, responsive design, and smooth user expeience.


### 3. Technologies Used

- Next.js (App Router)
- React.js
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify
- Lucide React Icons
- React Icons
- Context API (State Management)
- REST API

### 4. Key Features
-- Browse a collection of workouts.
  - Exercise name
  - Equipment
  - Difficulty level
  - Duration
  - Calories
  - Rating
 
### 5. My Plan Dashboard
  - Manage today's workout plan.
  - View saved workouts.
  - Track:
  - Total exercises
  - Total minutes
  - Total calories
  - Remove completed or unwanted workouts.

### 6. Smart Sorting System
  - Sort workouts based on:
  - Duration
  - Calories
  - Rating
  - Dynamic list update without page refresh.

### 7. User Friendly Experience
  - Loading js component/page
  - Custom 404 and error handling pages.
  - Toast notifications
  - Add workout
  - Remove workout
  - Mark workout as completed
